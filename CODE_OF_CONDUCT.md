# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and constructive. Harassment or abuse is not tolerated. Report concerns
privately via a [GitHub security advisory](https://github.com/TegroTON/wallet-mcp/security/advisories/new); maintainers will review and respond in good faith.
